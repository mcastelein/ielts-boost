# Weekly Content Templates

Seven repeatable post templates — one per day of the week. Together they cover the full IELTS pain spectrum: pain, aspiration, action, authority.

Every post must pass the **save test**: *"Will someone save this?"* If no, rewrite or skip.

All seven templates share the visual system in `05_visual_style.md` and the mascot in `06_mascot_spec.md`. Only the *content shape* changes per template.

## Weekly posting plan

| Day | Template | Theme |
|---|---|---|
| Mon | T1 — You're Losing Points Here | Mistakes |
| Tue | T2 — Band 6 vs Band 8 | Comparison |
| Wed | T3 — Say This Instead | Phrase upgrade |
| Thu | T4 — Real Answer Fix | Transformation |
| Fri | T5 — Exam Strategy | Strategy |
| Sat | T6 — Myth Busting | Pattern interrupt |
| Sun | T7 — Mini Lesson / Formula | Mini lesson |

Cycle weekly with new topics.

## T1 — "You're Losing Points Here"

**Goal:** Awareness + pain
**Why it works:** highly shareable, instant relatability
**Status:** This is the slideshow #1 template — fully documented in `07_slide_templates.md`

**Structure (6 slides):**
1. Hook — bold stat / claim ("90%的雅思考生都在这里丢分！")
2. Error ①
3. Error ②
4. Error ③
5. Fix — "这样改，立刻提分！"
6. CTA — IELTSBoost.AI

**Topic ideas:**
- Writing Task 2 essay structure mistakes
- Speaking Part 2 fluency killers
- Task 1 (GT) letter tone mistakes
- Common 中式英语 phrases that tank your score
- Vocabulary repetition traps

**Save trigger:** "I might be making this mistake — let me check later."

## T2 — "Band 6 vs Band 8"

**Goal:** Show the gap between average and high-band performance
**Why it works:** highest viral potential — directly addresses aspiration

**Structure (6 slides):**
1. Hook — "6分 vs 8分 差在哪？"
2. Band 6 example (English text in red-bordered card)
3. Why it's weak — 3 short reasons in Chinese
4. Band 8 version (English text in green-bordered card)
5. Why it's strong — 3 short reasons
6. CTA — IELTSBoost.AI

**Topic ideas:**
- Task 2 introduction paragraph
- Task 1 overview sentence
- Speaking Part 2 opening
- Speaking Part 3 opinion answer
- Linking words and discourse markers

**Visual notes:**
- Slide 2 example card: red top border, "Band 6" red pill label
- Slide 4 example card: green top border, "Band 8" green pill label
- Cat mascot: disapproving on slide 2, enthusiastic on slide 4

**Save trigger:** "I want to study the Band 8 version later."

## T3 — "Say This Instead"

**Goal:** Quick vocabulary upgrade — saveable, screenshot-worthy
**Why it works:** super saveable, immediately actionable

**Structure (6 slides):**
1. Hook — "别再说这个了"
2. Bad → Better → Best (item 1)
3. Bad → Better → Best (item 2)
4. Bad → Better → Best (item 3)
5. Summary tip — when to use which
6. CTA — IELTSBoost.AI

**Topic ideas:**
- very good → beneficial → highly advantageous
- important → significant → paramount
- a lot of → numerous → a substantial number of
- I think → In my opinion → It is widely believed that
- because → due to → owing to the fact that

**Visual notes:**
- Each upgrade slide: three stacked pill bars — red ❌ "Bad", yellow ⚠ "Better", green ✅ "Best"
- Cat mascot: skeptical on Bad, neutral on Better, enthusiastic on Best

**Save trigger:** "Screenshot this and use it tomorrow."

## T4 — "Real Answer Fix"

**Goal:** Show full transformation of a real student answer
**Why it works:** feels like real teaching, builds trust fastest

**Structure (6 slides):**
1. Hook — "这段只能拿6分"
2. Original answer (full English paragraph in card)
3. Highlight problems — annotated with red marks
4. Improved version (full English paragraph in card)
5. Key changes — bullet list of 3–4 specific upgrades
6. CTA — IELTSBoost.AI

**Topic ideas:**
- Task 2 body paragraph rewrite
- Task 1 trend description rewrite
- Speaking Part 2 cue card response rewrite
- IELTS letter (GT) opening rewrite

**Visual notes:**
- Slide 2: white card with red underlines + ❌ marks on weak phrases
- Slide 4: white card with yellow underlines on upgraded phrases
- Cat mascot: critical on slide 3, enthusiastic on slide 4

**Save trigger:** "This rewrite is a model I can copy."

## T5 — "Exam Strategy"

**Goal:** Practical tactical advice for test day
**Why it works:** practical = high save rate

**Structure (6 slides):**
1. Hook — "这样分配时间" / "考前必看"
2. Step 1 / Strategy point 1
3. Step 2 / Strategy point 2
4. Step 3 / Strategy point 3
5. Common mistake to avoid
6. CTA — IELTSBoost.AI

**Topic ideas:**
- Writing time split (planning 5min / Task 1: 20min / Task 2: 35min / review: 5min)
- Speaking structure (Part 1 short / Part 2 4-step formula / Part 3 opinion + example)
- Reading skim-and-scan order
- Listening note-taking shortcuts
- What to do in the last 5 minutes

**Visual notes:**
- Each step slide: large numbered circle + Chinese label + brief one-line explanation
- Slide 5: red ❌ pill with "千万别这样做"
- Cat mascot: pointing pose on each step, alert on the mistake slide

**Save trigger:** "I want this checklist for test day."

## T6 — "Myth Busting"

**Goal:** Pattern interrupt — challenge a widespread belief
**Why it works:** drives comments and engagement

**Structure (6 slides):**
1. Hook — "这个说法是错的"
2. Common belief (in quote marks, big text)
3. Why it's wrong — 2–3 short reasons
4. What's actually true
5. What to do instead — actionable advice
6. CTA — IELTSBoost.AI

**Topic ideas:**
- "用复杂词就能高分" ❌
- "字数越多分数越高" ❌
- "模板背得越多越好" ❌
- "口语必须像母语者一样" ❌
- "雅思写作必须用名人名言" ❌

**Visual notes:**
- Slide 2: large quote in white card with red ❌ overlay
- Slide 4: same format with green ✅ overlay
- Cat mascot: skeptical on slide 2, confident on slide 4

**Save trigger:** "Wait, I believed this — I should remember the truth."

## T7 — "Mini Lesson / Formula"

**Goal:** Teach a memorable, repeatable formula
**Why it works:** gives the viewer a tool they can use immediately

**Structure (6 slides):**
1. Hook — "记住这个结构" / "记住这个公式"
2. Formula introduced (e.g. P + E + E + L)
3. Component 1 explained
4. Component 2 explained (or 3+4 combined)
5. Full example using the formula
6. CTA — IELTSBoost.AI

**Topic ideas:**
- 观点 + 解释 + 例子 + 总结 (Task 2 body paragraph)
- PEEL paragraph structure
- Speaking Part 2 4-step formula (Who / What / When / Why)
- Task 1 overview formula (general trend + key feature)
- Linking word menu organized by function

**Visual notes:**
- Slide 2: large formula displayed as connected pills (P + E + E + L)
- Slide 5: full English example with each formula component highlighted in a different color
- Cat mascot: teaching pose throughout, pointing at the formula

**Save trigger:** "I'll memorize this formula and reuse it forever."

## How to use these with the image generator

For each daily post:

1. Pick the template for the day from the table above
2. Pick a topic from the template's topic ideas (or generate a new one)
3. Fill the per-slide slot template in `08_generation_prompts.md` for each of the 6 slides
4. Generate the mascot reference once (or use the canonical logo file), then attach to every slide prompt
5. Review for character consistency and Chinese text fidelity before posting
6. Post per `10_workflow.md`

## Coverage check

The seven templates together cover:

- **Pain** (T1, T6) — what's wrong, what's a myth
- **Aspiration** (T2, T4) — what good looks like
- **Action** (T3, T5, T7) — phrases, strategies, formulas
- **Authority** — woven throughout via specific, expert-level corrections

This is what builds trust and drives conversions. Stick to the rotation rather than chasing trends — the system compounds.
