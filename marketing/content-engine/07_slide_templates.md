# Slide Templates — Template 1 reference

This file documents the canonical slide-by-slide breakdown of slideshow #1, which is **Template 1 ("You're Losing Points Here")** in the weekly system. For the full set of seven weekly templates, see `11_weekly_templates.md`.

Use this file as the deep-dive reference whenever you need to reproduce the T1 pattern. All slides use the visual system in `05_visual_style.md` and the mascot from `06_mascot_spec.md`.

## Slide 1 — Hook

**Copy**
```
90%的雅思考生
都在这里丢分！
⚠ 这3个错误正在拉低你的分数
```

**Visual treatment**
- Huge two-line headline; `90%` and `丢分` accented in deep purple, yellow wavy underline under `丢分`
- Sub-line in a small purple pill below the headline
- Cat: serious, pointing, lower-right
- Background sparkles + dotted pattern upper-left

## Slide 2 — Error ①

**Copy**
```
❌ 错误①
观点不明确
问题: 考官看不出你是支持还是反对
Example: Some people think it's good, others think it's bad.
Cat bubble: 你到底想表达什么？
```

**Visual treatment**
- Red ❌ pill with `错误①` at top
- Purple `问题:` tab beneath the headline
- White example card; `Some people think` and `others think` underlined in yellow
- Cat: confused, with `?` marks floating around head

## Slide 3 — Error ②

**Copy**
```
❌ 错误②
论证太简单
问题: 没有具体例子
Example: It is convenient.
Cat bubble: 太空洞，拿不到高分！
```

**Visual treatment**
- Same red ❌ pill template
- Yellow underline under `convenient`
- Cat: disapproving, holding a red ❌

## Slide 4 — Error ③

**Copy**
```
❌ 错误③
词汇太基础
Example: good   good   good
Cat bubble: 一直用 good = 6分水平
```

**Visual treatment**
- Three `good` pills in a row inside the example card, all underlined yellow
- Cat: skeptical, winking, ironic thumbs up

## Slide 5 — Fix

**Copy**
```
✅ 这样改，立刻提分！
结构: 观点 + 例子 + 连接词
  💡 观点 — 清晰表达你的立场
  📄 例子 — 用具体例子支撑观点
  🔗 连接词 — 让逻辑更清晰，更有说服力
Example: The advantages far outweigh…
Cat bubble: 这才是 7+！
```

**Visual treatment**
- Green ✅ pill with `这样改`
- Three purple icon circles in a horizontal row (idea / document / link icons)
- Example card with key phrase underlined in yellow
- Cat: enthusiastic, strong thumbs up, sparkles

## Reusable slot recipe (for new T1 posts)

Replace the contents while keeping these slots:

1. **Hook:** stat or bold claim + sub-warning
2. **Error ①:** label + 问题 line + English example + cat reaction
3. **Error ②:** same structure
4. **Error ③:** same structure
5. **Fix:** 3-step structure with icons + improved English example + cat approval
6. **CTA:** question hook + IELTSBoost.AI pill + 2 feature pills + cat invitation
