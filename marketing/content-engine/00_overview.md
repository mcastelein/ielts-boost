# IELTSBoost Content Engine

This system generates short-form educational slide content for Douyin and Xiaohongshu.

Goal:
- Attract Chinese IELTS learners
- Provide high-value micro-lessons
- Convert users to IELTSBoost.AI

Core funnel:
Content → Profile → Website → AI usage

Content format:
6-slide vertical carousel (1080x1920)

Each post:
- Hooks attention
- Shows mistakes
- Provides improvement
- Ends with CTA to IELTSBoost.AI
