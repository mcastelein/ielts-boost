# Process notes for Agent 3 (review) & Agent 4 (improvement)

**For Agent 3 — review checklist:**
- Does each post follow the T1 6-slide structure exactly?
- Are the 3 errors per post genuinely distinct (not 3 variations of the same mistake)?
- Are English example sentences realistic Chinglish (i.e. things Chinese learners actually write/say), not strawmen?
- Is the fix slide actionable in <10 seconds of reading?
- Do `{P}`, `{H}`, `{Y}` markup tags wrap the right scope of text (key word, not whole sentence)?
- Speech bubbles: short, sassy, Chinese, character-feel?
- CTAs: end with `能拿几分？` or similar score-curiosity hook?
- No topic overlap with drafts 01–05?

**For Agent 4 — improvement observations from Agent 2:**
- Template T1 is rigid but productive — every post comes out structurally identical. Pro: brand consistency. Con: feed feels repetitive after 5+ posts. Worth considering a T2/T3 template alongside.
- The 3-error format forces invented variety; some topics (e.g. articles) genuinely have 3 distinct errors, others (e.g. hedging) are forced to split one idea into 3.
- Card body English examples need a native check — some may already be slightly unidiomatic.
- Slug + post_meta should be carried into final JSON; this markdown is intentionally one step before that.
- Idea pipeline: I've drained "grammar mistake" and "vocab" topics. Future categories worth exploring: exam strategy (timing, planning), scoring criteria explainers, before/after sample rewrites, student Q&A style, "myth vs reality" format.
